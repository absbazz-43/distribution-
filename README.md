StatVizPro: Distribution Analyzer & Study Designer

Interactive Shiny app for visualizing 9 probability distributions (Uniform, Normal, Binomial, etc.) with real-time parameter adjustment. Features PDF/PMF, CDF, and simulation plots with side-by-side distribution comparison. Includes two practical sample size calculators: Cochran's formula for surveys and power analysis for experiments. Educational tool bridging statistical theory with research design. Perfect for students, educators, and researchers
